# Knowledge base

Curated knowledge that feeds the models: books, papers, proceedings and field experience.

| Folder | Committed? | Contents |
|---|---|---|
| `notes/` | Yes | Our own structured notes: equations, parameter tables, classification systems, each with the source (book/chapter/page) |
| `books/` | **No** (gitignored) | Copyrighted books (PDF/EPUB/scans), e.g. the rock-mechanics textbook. Drop files here to have them read and summarised into `notes/` |
| `private/` | **No** (gitignored) | Local inventories, extracted proceedings text, confidential client material (e.g. machine signal lists) |

Rules:

- Never commit copyrighted text, figures or standards.
- Write notes in your own words with page references. Equations and numerical values may be recorded with their source.
- Client or partner material (signal lists, machine data) stays in `private/` unless the owner licenses it for publication (CC-BY-4.0 or CC0 preferred).
